# Edu+ para criadores de conteúdo

Influenciadores transformam o próprio conteúdo em trilhas de microaulas gamificadas com o Edu (IA) e vendem por assinatura aos seguidores.

- **Painel do criador:** `apps/painel` → criador.edumais.app.br
- **App do aluno:** `apps/app` → aprenda.edumais.app.br
- **Site:** `apps/site` → edumais.app.br

## Começando

```bash
nvm use            # Node 22
corepack enable    # pnpm 10
pnpm install
pnpm verificar     # lint, tipos e testes, igual ao CI
```

Arquitetura, glossário e regras do projeto: [AGENTS.md](AGENTS.md).
